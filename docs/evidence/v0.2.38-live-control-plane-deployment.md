### Zero-row edge table — explicit limitation

The zero-row `repository_index_edges` table means the **schema is deployed** but
**live call-edge retrieval is NOT yet proven**. Table existence alone is not
retrieval success. A post-deployment repository index refresh and a live review
exercise are still required before any call-edge or descriptor-first retrieval
claim.

This observation also does **not** prove live ANN performance, non-empty durable
edges after refresh, live descriptor-first review on a pull request, or history
retrieval.
