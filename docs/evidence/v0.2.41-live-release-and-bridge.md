## Negative control and trust boundary

Negative control [guardianbot PR #47](https://github.com/geekyshubham/guardianbot/pull/47)
put `benchmark-review` only on the PR head while the base lacked that setting.
Review correctly stayed unavailable.

Trust boundary: repository review configuration loads from the exact base SHA.
A pull request cannot redirect its own review by changing config only on the
PR head.
