## Measured Swift indexing capacity

The exact signed Linux image was run against the current
`vibeproxy-ultra` default-branch snapshot:

- 60 Swift/Python source files and 972,913 source bytes were selected.
- A 2 GiB cgroup terminated the index process with exit 137.
- A 4 GiB cgroup completed in about 20 seconds.
- The result contained 949 unique symbols and a 6.4 MB serialized index.

The production control plane therefore uses 4 GiB while it runs Tree-sitter
inside the web/worker process. Separating indexing into its own resource-limited
worker remains production-hardening work; reducing the instance below 4 GiB is
not supported while Swift indexing is enabled.
