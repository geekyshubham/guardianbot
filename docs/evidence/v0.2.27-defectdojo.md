A dedicated `guardianbot-automation` API identity with an unusable interactive
password was created. Its token is stored only on the DefectDojo host and in the
DigitalOcean control-plane runtime secret; it was never written to a consumer
repository or evidence artifact.

The confirmed live conformance command used run ID `20260729T1805Z` and:

1. ensured the `GitHub Repositories` product type;
2. ensured the isolated `guardianbot/defectdojo-conformance` product;
3. ensured engagement `conformance/20260729T1805Z`;
4. imported the non-secret empty Semgrep fixture as test `1`; and
5. reimported the same fixture into test `1`.

The first attempt exposed that DefectDojo rejects tag values containing spaces.
GuardianBot now canonicalizes spaces, commas, and quotes in all generated and
custom tags, then sorts and de-duplicates the result. Package tests and the
subsequent live import/reimport passed.
