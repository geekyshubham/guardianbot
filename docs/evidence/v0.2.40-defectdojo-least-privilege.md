# v0.2.40 DefectDojo least-privilege automation cutover

Verified: 2026-08-02 UTC

Live cutover of the GuardianBot control-plane DefectDojo automation identity
from an overprivileged staff/superuser token to a non-staff, non-superuser OSS
identity authorized only on Product Type ID 2 `GitHub Repositories`. Same signed
`v0.2.40` image digest; environment-only DigitalOcean deployment. Tokens,
passwords, and secrets are never recorded here.

This does **not** claim RouteLens current-binding full DAST/import, production
model credential/live AI review, seven-day enforcement, GitHub App
review-comment subscription, cross-week monitoring, restore/HA evidence, or full
PoC acceptance. Credential rotation is **not** fully closed until the old token
is reset/revoked and the old superuser account is deactivated through an
approved DefectDojo admin path.
