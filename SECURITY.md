# Security policy

Report vulnerabilities privately through GitHub security advisories for this
repository. Do not include live credentials, private repository contents, staging
sessions, or exploit data in public issues.

Supported releases are the latest signed minor release and its immutable workflow
commit. GuardianBot treats repository content and model output as untrusted,
never grants models tools or credentials, and keeps AI findings advisory.

Operators should immediately rotate affected App, webhook, bridge, DefectDojo, or
staging credentials and follow the compromised-bridge or emergency-disablement
runbook. Scanner evidence and retained audit records must be preserved.
